Знак

C — от CRC. Каретка рядом говорит, что это редактор, срез угла — что блок это файл кода. Всё задано в процентах от стороны, поэтому одни и те же числа питают SVG-ассеты и тот знак, который редактор рисует сам у себя в заголовке.

Что работает

  • Редактирование — печать, выделение, движение по словам и строкам, отмена и возврат
  • Мышь — клик ставит каретку, протяжка выделяет, колесо прокручивает
  • Вкладки — несколько файлов сразу, у каждого свой курсор и своя история
  • Автосохранение — через 800 мс после последнего нажатия, при потере фокуса и при закрытии
  • Подсветка — 12 языков, пересчёт на каждое нажатие
  • Своё окно — без системной рамки, кнопки как на маке, ресайз за края, масштаб под DPI
  • Две темы и три профиля плотности, плюс zen

Чего ещё нет

Командная палитра, поиск по файлу, разделение панелей
LSP: диагностика, переходы, автодополнение
Панель агента Claude Code
Совместное редактирование по сети — примитивы в буфере есть
Плеер, видеоредактор, мини-Figma — записаны в план как отдельные подсистемы

Как запустить

cargo run -p crc-app # открыть текущую папку
cargo run -p crc-app -- ../other # открыть другую
cargo test --workspace # 273 теста

13 коммитов, каждый в паре с Claude Code. Тесты не притворяются: контраст считается из настоящей палитры, грамматики грузятся и разбирают настоящие куски кода, кадры рисуются на реальной видеокарте и читаются обратно по пикселям.
